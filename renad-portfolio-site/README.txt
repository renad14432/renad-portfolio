RENAD portfolio — ready to run, no installation needed.

1) Double-click index.html (or renad-portfolio-single.html) to open it in a browser.
2) Edit your links: open data.js and fill in contact = { email: '', linkedin: '', x: '' }
   (full https:// links for linkedin and x). Until then the contact buttons show "coming soon".
3) Change images: replace files in the assets/ folder with the same names.
4) Language button (header): switches English / Arabic (RTL) and remembers the choice.
5) Publish: upload this whole folder to Netlify Drop / Vercel / GitHub Pages (index.html is the entry).

Notes
- Fonts load from Google Fonts when you are online; offline the site uses system fonts.
- Certificate images show certificate numbers and QR codes; blur them before publishing if you prefer.
- Arabic text is a first draft; review it in data.js and app.js.
