RENAD portfolio — built directly from your design boards (desktop + phone).

OPEN IT
- Double-click renad-portfolio-single.html (everything inside one file), or index.html in this folder (needs the assets folder next to it).
- Desktop width (900px and up) uses your desktop boards; phones/narrow screens use your phone boards.

WHAT WORKS
- Header links, Explore My Work, footer links and the project index rows move between pages with the transition; phone menu opens from the menu button.
- Arabic / English button, dark / light button, CV download (assets/Renad_Aladwani_Resume.pdf), "Show all certificates" button.
- Arabic is a first draft; please review it (project names and the cat's keyboard stay in English).

EDIT
- The pages are generated from the design boards (boards.js). To change text/design, change the board in the design canvas and ask for a re-export.
- Replace the CV PDF in assets/ with the same file name.

PUBLISH
- Upload this whole folder to Netlify Drop, Vercel, or GitHub Pages (index.html is the entry point).

NOTES
- Fonts load from Google Fonts when online; offline the site uses system fonts.
- Certificate images show certificate numbers and QR codes; blur them before publishing if you prefer.
- Your phone number is NOT published anywhere on the site (it is only inside the CV PDF).
